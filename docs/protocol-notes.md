# IEC 60870-5-103 规约实现笔记（DL/T 667-1999）

本仓库 103 栈（`IecTestbench.Core/Iec103/`）的实现依据与多源核对记录。
实现过程中三处易错点（帧格式、COT 表、ASDU 布局）均经独立来源交叉裁决。

| 来源 | 用途 |

## 1. 链路层（FT1.2，与 101 同款）

| 帧型 | 布局 | 校验 |
|---|---|---|
| 固定帧 | `10 C A CS 16`（5 字节） | CS=(C+A) mod 256 |
| 变长帧 | `68 L L 68 C A <ASDU> CS 16` | L=C+A+ASDU 长度；CS=自 C 起算术和 mod 256；总长=L+6 |
| 单字符 | `E5` | — |

控制域：bit6 PRM、bit5 FCB|ACD、bit4 FCV|DFC、bit0-3 功能码。

| 方向 | 功能码 | |
|---|---|---|
| 主站→从站 | 0 复位 CU（0x40） | 3 发送/确认（0x53/0x73） | 4 发送/无回答 | 7 复位 FCB | 9 请求链路状态 | 10 召 1 级（0x5A/0x7A） | 11 召 2 级（0x5B/0x7B） |
| 从站→主站 | 0 ACK | 1 NACK | 8 以数据响应（0x08） | 9 无所召唤数据 | 11 链路状态 |

主站每轮 SEND/CONFIRM 或 REQUEST 服务翻转 FCB；复位命令 FCB=0 FCV=0。

## 2. 传输原因（COT，1 字节，bit7=P/N）

**103 与 101/104 在 3 之后分道**（双源核对 + ZLG 实测印证）：

| COT | 103 含义 | 101/104 对照 |
|---|---|---|
| 1/2 | 突发 / 周期循环 | 1 周期 / 2 背景（**语义互换**） |
| 3/4 | 复位 FCB / **复位 CU** | 3 突发 / 4 初始化 |
| 5 | 启动/重启（ZLG 标识第二帧 COT=5） | 请求或被请求 |
| 6/7 | 上电 / 测试模式 | 激活 / 激活确认 |
| 8/9/10 | 时间同步 / 总召唤启动 / 总召唤终止 | 停止激活系列 |
| 11/12 | 远方/当地操作（亦作命令返送） | 远方/当地命令返送 |
| 20/21 | 命令肯定/否定确认 | 20 响应站召唤 |
| 31 | 扰动数据传输 | — |
| 40-44 | 通用分类：写命令肯定/否定确认、读响应有效/无效、写确认 | — |

工程决策：总召唤数据点回送用 COT=11（工程通行；部分装置用 5/9）——集中于 `Cot103.RemoteOperation` 常量。

## 3. ASDU 布局

通用头：`TI(1) VSQ(1) COT(1) CA(1) FUN(1) INF(1)` + 数据。FUN=255 全局、254 通用分类（GEN）、160-255 专用范围、0-127 兼容范围。

| TI | 名称 | 数据布局（FUN/INF 之后） |
|---|---|---|
| 1 | 带时标监视信息 | DPI(1)+4×FF 附加字节+CP56(7)——ArIEC 实现用 DPI(1)+5 字节 CP32 变体，解码按长度容错 |
| 2 | 带相对时标监视信息（专用范围） | DPI(1)+RET(2 LE ms)+FAN(2 LE)+CP56(7) |
| 5 | 标识报文 | 8 字节 ASCII（FUN=255 INF=80 兼容/81 专用；COT=4/5） |
| 6 | 时间同步 | CP56(7)。主站 FUN=0（ZLG 实测），从站回读 FUN=255 COT=8 |
| 7 | 总召唤 | SCN(1)（FUN=255 INF=0 COT=9） |
| 8 | 总召唤终止 | SCN(1)，COT=10 |
| 9 | 测量值（2 级循环） | int16 LE（ArArIEC 变体第 3 字节附加 0x00，读取前 2 字节即可） |
| 10 | 通用分类数据（**双向**） | RII(1)+NGD(1)+N×[GIN(2)+KOD(1)+GDD(3)+GID]。COT：40 主站写/40、41 写确认/42 读响应/43 无效 |
| 11 | 通用分类标识 | RII+GIN+NDE+描述元素 |
| 20 | 一般命令 | DCO(bit6-7)+RII，COT=20 |
| 21 | 通用分类读命令 | RII+NOG+N×[GIN+KOD]，COT=42；全目录=GIN 0000+KOD=10 |
| 23 | 被记录扰动表 | N×[FAN(2)+SOF(1)+CP56(7)] |
| 24/25 | 扰动命令/认可 | TOO(1)+TOV(1)+FAN(2)+ACC(1) |
| 26 | 传输准备就绪 | TOO+TOV+FAN+NOF(2)+NOC(1)+NOE(2)+INT(2µs)+CP32(4) |
| 27 | 通道一次值 | TOO+TOV+FAN+ACC+RPV(4f)+RSV(4f)+RFA(4f) |
| 29 | 扰动标签 | FAN+NOT(1)+TAP(2)+NOT×[FUN+INF+DPI] |
| 30 | 通道扰动数据段 | TOO+TOV+FAN+ACC+NDV(1)+NFE(2)+NDV×int16(归一化) |
| 31 | 通道/扰动传输终止 | TOO+TOV+FAN+ACC（TOO=35 通道结束、32 扰动结束） |

关键枚举：KOD（1 实际值/2 缺省/3 量程/**10 描述**）、GDD 类型（1 ASCII/3 UI/4 I/7 R32.23 float/22 回复码/23 结构）、TOO（1 选故障/2 请求数据/8 请求通道/16 请求标签/24 请求扰动表/32/35/38 结束/64/65 认可）、NGD（数目 bit2-7|后续 bit0）、GDD（类型+宽度+数量 bit1-7|连续 bit0）。

## 4. 时标变体

- **CP56Time2a**（7 字节）：ms(LE16 含秒 0-59999)+min(bit7 IV)+hour(bit7 SU)+日/月/年。TI=1/2/6 使用。
- **CP32Time2a**（4 字节）：ms(LE16)+min+hour。ASDU 26 使用。
- **装置变体**：ArIEC103 的 TI=1 附 5 字节时标（ms2+min+hour+1）。本工具主站解码按数据长度自适应（≥12→CP56；≥6→短时标）。

## 5. 服务流程

### 总召唤
主站 TI=7（FUN=255 INF=0 COT=9）→ 从站 ACK → 数据经 1 级召唤逐帧取出（逐点 TI=1，COT=11）→ TI=8 COT=10 终止。复位 CU 后从站先应答两帧标识（TI=5，COT=4/5，仿 ZLG E8000 实测行为）。

### 通用分类
读全目录（GIN 0000+KOD 描述）→ 从站分帧回 ASDU 10（NGD 后续标志续传，COT=42）；单条读（描述/实际值/量程）；写值（TI=10 COT=40）→ 确认（COT=40/41 + GRC 回复码：0 认可/2 GIN 不存在/7 只读）。描述文本 OS8ASCII 以 **GB18030** 编码（国内装置通行 GB2312 中文）。

### 扰动传输（TOO 驱动）
```
主站 ASDU24 TOO=24 ─→ ASDU23 扰动表
主站 ASDU24 TOO=1(FAN) ─→ ASDU26 就绪（NOC/NOE/间隔/时刻）
主站 ASDU25 TOO=64 ─→ （认可）
主站 ASDU24 TOO=2 ─→ ASDU27 × 每通道（一次值/二次值/因数）
主站 ASDU24 TOO=8(ACC) ─→ ASDU30 数据段（分帧）+ ASDU31 TOO=35 通道结束
全部通道完成 ─→ ASDU31 TOO=32 扰动结束
```

## 6. 对拍认知（vendored ArIEC103 互操作）

- ArIEC103 保护状态机**由收帧驱动**（trip 定时从主站下一帧处理时刻起算）——主站轮询间隔须大于 trip 延时才能顺序取到启动/跳闸两事件。
- ArIEC103 GI 快照：6×DPI（FUN160/161 三相）+3×测量+标识+GI END，全部经 1 级队列。
- 坏校验帧（bad-checksum 模式）被我方分帧器正确舍弃，链路服务超时恢复符合预期。
